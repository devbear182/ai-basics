# Structural Rules

Every chapter should:

* continue naturally from the previous one
* solve one realistic developer problem
* introduce only the concepts needed
* finish with a Level Up section
* prepare the reader for the next challenge

Avoid topic-driven chapters.

Prefer problem-driven progression.
