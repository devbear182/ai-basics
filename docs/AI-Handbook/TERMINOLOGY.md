# Terminology

## AI

Artificial Intelligence.

The umbrella term covering systems capable of performing tasks normally requiring human intelligence.

---

## Model

A trained neural network capable of performing one or more tasks.

Examples:

- GPT
- Claude
- Qwen
- Llama

---

## Foundation Model

A general-purpose model trained on large amounts of diverse data.

Foundation models serve as the basis for many downstream applications.

---

## Large Language Model (LLM)

A foundation model specialized in understanding and generating text.

---

## Multimodal Model

A model capable of processing more than one data type.

Examples:

- text
- images
- audio
- video

---

## Runtime

Software responsible for loading and executing AI models.

Example:

Ollama.

---

## Application

Software through which users interact with AI.

Examples:

ChatGPT

Open WebUI

Claude Desktop

Continue

---

## Platform

A complete ecosystem providing applications, APIs, models and infrastructure.

Examples:

OpenAI

Anthropic

Google AI

Microsoft AI

---

## Context

Information available to the model during inference.

---

## Context Window

Maximum number of tokens processed during one request.

---

## Token

Smallest text unit processed by a language model.

---

## Parameter

A learned numerical value inside a trained neural network.

---

## Prompt

Instructions intentionally supplied to guide model behaviour.

---

## System Prompt

Hidden instructions supplied by an application before the user's prompt.

---

## RAG

Retrieval-Augmented Generation.

A technique that retrieves external information before generating a response.

---

## Agent

Software that combines an AI model with tools, memory and workflows to accomplish tasks autonomously.
