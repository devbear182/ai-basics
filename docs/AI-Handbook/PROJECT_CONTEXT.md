# PROJECT_CONTEXT.md

# Project Context

## Project

AI Basics Handbook

---

# Vision

Create a practical handbook that teaches software developers how to understand, build and engineer modern AI systems.

The handbook should remain useful despite rapid changes in models and tools.

Instead of focusing on today's products, it focuses on durable concepts and engineering principles.

---

# Target Audience

Primary audience:

* Windows developers
* Junior to intermediate software developers
* Developers familiar with Git, C#, .NET and Visual Studio / VS Code
* Readers with little AI experience

The reader already understands software engineering.

The handbook provides the missing AI knowledge.

---

# Overall Learning Journey

The reader progresses through several capability levels.

Understand

↓

Use

↓

Reuse

↓

Automate

↓

Engineer

↓

Optimize

Each chapter unlocks one additional capability.

---

# Educational Philosophy

The handbook is problem-driven.

Every chapter starts with a realistic developer problem.

New concepts are introduced only when they solve the current problem.

Avoid introducing concepts merely because they exist.

---

# Scope

The handbook focuses on practical AI engineering.

Topics include:

* AI terminology
* Foundation Models
* LLMs
* Local AI
* Ollama
* Open WebUI
* Prompting
* Context Engineering
* Instructions
* Skills
* Agents
* Memory
* RAG
* MCP
* AI security
* AI architecture
* AI optimization

The emphasis is on understanding how these components work together.

---

# Long-Term Goal

The reader should eventually be capable of:

* building a local AI assistant
* extending it safely
* integrating it into software development workflows
* teaching it project-specific knowledge
* engineering reusable AI systems
* evaluating future AI technologies independently

---

# Current Status

Part I is largely complete.

Part II is currently transitioning from infrastructure setup towards practical developer workflows.

The next chapters focus on gradually transforming a general-purpose model into a project-aware development assistant.

---

# Important Design Principles

* Windows-first
* Software engineering analogies
* Practical examples
* Progressive learning
* Minimal repetition
* Stable terminology
* Clear hierarchy
* Practical before theoretical whenever possible

The handbook should feel like learning from an experienced colleague rather than reading academic documentation.
